🌾 Level 2: FIRST HARVEST

Role: Farmer • Crop Lifecycle on Plot A1
WHERE • UPDATE • Day Advancement

📖 Story & Cinematic: Chapter 2 — First Harvest & Morning Dew

Starting cash (₹500) won't last long. Uncle Somu guides you to locate available soil, sow tomato seeds, water them over consecutive farm days, harvest 40kg of tomatoes with the tractor, and sell them for ₹800 revenue!

🎯 Chapter Missions
1. Query Available Plots & Plant SeedL2_M0 - L2_M2

Filter plots with status = 'available', deduct 1 seed, and record planting in farming table.

UPDATE seeds SET quantity = quantity - 1 WHERE seed_name = 'Tomato'; INSERT INTO farming (plot_id, crop_id, status, growth_percent) VALUES ('A1', 'Tomato', 'growing', 0); UPDATE plots SET status = 'occupied' WHERE plot_id = 'A1';
2. Advance Day & Harvest 40kg YieldL2_M3 - L2_M4

Advance days until tomatoes reach 100% growth, then store 40kg in warehouse stock.

UPDATE farming SET status = 'harvested' WHERE plot_id = 'A1'; UPDATE plots SET status = 'available' WHERE plot_id = 'A1'; INSERT INTO stock (product_name, quantity, unit, price) VALUES ('Tomato', 40, 'kg', 20);
3. Sell Produce at MarketL2_M5

Fulfill Green Grocers order and collect ₹800 cash.

UPDATE stock SET quantity = quantity - 40 WHERE product_name = 'Tomato';

📊 Level 3: THE FARM GETS BUSY

Role: Farm Operator • Plot A2 Unlocked
ORDER BY • GROUP BY • COUNT / SUM / AVG • HAVING

📖 Story & Cinematic: Chapter 3 — The Bustling Farmland

Harvest revenue pays off the lease for Plot A2! With Wheat, Rice, Corn, and Tomatoes pouring in, Uncle Somu teaches statistical aggregation to benchmark high-yield crops.

Sort & Aggregate Warehouse InventoryL3_M2 - L3_M5
SELECT product_name, SUM(quantity) AS total_yield, AVG(price) AS avg_price FROM stock GROUP BY product_name HAVING SUM(quantity) >= 80 ORDER BY total_yield DESC;

🌐 Level 8: THE EXPANSION

Role: Expansion Manager • 4 Regional Facilities
WITH Common Table Expressions (CTEs)

📖 Story & Cinematic: Chapter 8 — Regional Farm Expansion

Farm North, Farm South, Farm East, and Home Farm unite into an 83-acre enterprise. Write modular WITH CTEs to benchmark cost-per-ton efficiency.

Benchmark Facility Unit Costs with CTEL8_M4
WITH UnitCostCTE AS ( SELECT facility_id, SUM(yield_tons) AS total_tons, SUM(production_cost) AS total_cost, ROUND(SUM(production_cost) / SUM(yield_tons), 2) AS cost_per_ton FROM regional_production GROUP BY facility_id ) SELECT * FROM UnitCostCTE ORDER BY cost_per_ton ASC;

👑 Level 9: THE AGRICULTURAL EMPIRE

Role: Agribusiness Executive • Statewide Analytics
Window Functions • RANK() • ROW_NUMBER() • OVER(PARTITION)

📖 Story & Cinematic: Chapter 9 — The Agribusiness Empire

Step into the corporate boardroom! Compute running cumulative cash flows and partition top-ranked crops per division without collapsing individual rows.

Running Totals & Crop RankingsL9_M1 - L9_M4
-- Running Cumulative Revenue SELECT *, SUM(monthly_revenue) OVER (PARTITION BY division ORDER BY month_num) AS running_rev FROM empire_revenue; -- Rank Crops per Facility SELECT facility_id, crop_name, yield_tons, RANK() OVER (PARTITION BY facility_id ORDER BY yield_tons DESC) AS yield_rank FROM regional_production;

🏆 Level 10: THE HARVEST DECISION (GRAND FINALE)

Role: Farm CEO • Centennial Drought Crisis
Full-Stack SQL Synthesis • JOIN + CTE + CASE

📖 Story & Cinematic: Chapter 10 — The Regional Drought Crisis

The worst drought in 50 years hits the valley! Only 18,000L of water remain. Synthesize water consumption, profit margins, and warehouse valuations in SQL to allocate crisis quotas and crown your journey as Sovereign Farm CEO!

Optimize Profit Margin per Liter & Final TriumphL10_M1 - L10_M4
WITH WaterEfficiency AS ( SELECT crop_name, ROUND(CAST(expected_market_price - cultivation_cost AS REAL) / water_liters_per_kg, 2) AS profit_per_liter FROM drought_metrics ) SELECT * FROM WaterEfficiency ORDER BY profit_per_liter DESC; -- Sovereign Grand Victory Query SELECT 'FARMDB EMPIRE SURVIVED & TRIUMPHED' AS status, SUM(s.quantity * d.expected_market_price) AS final_treasury_revenue FROM stock s INNER JOIN drought_metrics d ON LOWER(s.product_name) = LOWER(d.crop_name);

⚙️ Client Architecture & Technologies

Three.js • SQLite WASM • Vanilla CSS

🚀 High Performance Zero-Dependency Architecture

FARMDB executes 100% in the client browser with zero server latency. Query mutations immediately trigger listeners that re-render 3D meshes, update water volumes, advance crop growth, and animate vehicles in real time.

SQLite WebAssembly Core (sql.js)

Direct in-memory relational engine executing standard ANSI SQL. Handles schema creation, relational integrity, transactions, joins, subqueries, and window functions.

Three.js WebGL 3D World

High-framerate 3D rendering with OrbitControls, directional shadows (PCFShadowMap), ACES Filmic tone mapping, skeletal FBX dog animations, and procedural instanced crops.

Web Audio API Sound Engine

Synthesized audio effects for water droplets, tractor engines, celebratory chimes, animal vocalizations, and ambient bird calls.
